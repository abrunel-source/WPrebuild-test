We're excited to launch the new version of our website. It was previously built
on WordPress using the **Hello Elementor** theme, and we've now rebuilt it from
the ground up with [Astro](https://astro.build).

## Why we moved

The original site used a classic WordPress + Elementor stack. That served us well,
but we wanted:

- **Speed** — Astro ships zero JavaScript by default, so pages load fast.
- **Simplicity** — content lives in Markdown files we can version with Git.
- **Portability** — the site is just static files that can be hosted anywhere.

## What stayed the same

We carried over the design system from the original `theme.json`:

- An 800px content width and 1200px wide width
- Clean, system-font typography
- The header (primary menu) and footer (secondary menu) layout

Thanks for reading, and welcome aboard!
